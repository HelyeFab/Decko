# Firebase setup (MVP_020, DEC-029)

Decko uses Firebase **Auth** + **Cloud Firestore** for a narrow, local-first
cloud sync: profile, safe settings, and the activity ledger (XP / streaks /
heatmap / history). It never syncs imported decks, media, FSRS, review-card
state, or due queues. Decko is fully usable signed-out and offline.

## What's already wired (project `decko-7a443`)

- iOS app registered; `lib/firebase_options.dart` + `ios/Runner/GoogleService-Info.plist` generated by `flutterfire configure`.
- Google sign-in: `GIDClientID` + the reversed-client-id URL scheme added to `ios/Runner/Info.plist`.
- iOS deployment target raised to 15.0 (Firebase SDK requirement) in the Podfile + Xcode project.
- Firestore security rules in `firestore.rules` (deployed): each user can read/write **only** `/users/{uid}/**`.
- Packages: `firebase_core`, `firebase_auth`, `cloud_firestore`, `google_sign_in`.

## Secrets

- The **Admin SDK service-account key** is server-side only and lives in
  `secrets/` (gitignored — `secrets/`, `*-firebase-adminsdk-*.json`). The Flutter
  client never uses it.
- `firebase_options.dart` and `GoogleService-Info.plist` are **client config**,
  not secrets (access is gated by the Firestore rules above). They are committed.

## One manual step — enable sign-in providers

In the Firebase console → **Authentication → Sign-in method**
(https://console.firebase.google.com/project/decko-7a443/authentication/providers),
enable:

1. **Anonymous** — toggle on, Save.
2. **Email/Password** — toggle on, Save.
3. **Google** — toggle on, pick a project support email, Save.

That's all that's needed for sign-in to work on-device.

## Regenerating config (e.g. adding Android)

```
dart pub global activate flutterfire_cli   # once
flutterfire configure --project=decko-7a443
firebase deploy --only firestore:rules
```

## Firestore shape

```
/users/{uid}/profile/main          # uid, email, displayName, createdAt, updatedAt
/users/{uid}/settings/app          # selectedThemeId, furiganaEnabled, dailyGoal, updatedAt
/users/{uid}/activityEvents/{id}   # the MVP_019 activity ledger, keyed by stable event id
```
